# پروژه پایانی یادگیری تقویتی: طراحی و تحلیل عامل هوشمند در هزارتوی پویا

شماره دانشجویی: 40415484

## خلاصه پروژه

این پروژه شامل طراحی یک محیط هزارتوی پویا و پیاده‌سازی سه الگوریتم یادگیری تقویتی زیر است:
- Value Iteration (model-based)
- Q-Learning (model-free, off-policy)
- SARSA(λ) (model-free, on-policy با Eligibility Trace)

همچنین این پروژه شامل بررسی انتقال یادگیری (Transfer Learning) و یک رابط گرافیکی تعاملی برای نمایش عملکرد الگوریتم‌هاست.

## پیش‌نیازها و نصب

برای اجرای پروژه به پایتون 3.8 یا نسخه‌های بالاتر نیاز دارید. برای نصب تمام نیازمندی‌ها، دستور زیر را در خط فرمان اجرا کنید:

```bash
pip install -r requirements.txt
```

## نحوه اجرا و بررسی نتایج

### 1. اجرای رابط گرافیکی
برای مشاهده محیط و عامل به صورت بصری و تست الگوریتم‌ها، دستور زیر را اجرا کنید:
```bash
python main.py
```
در رابط کاربری باز شده می‌توانید نوع الگوریتم را مشخص کرده و روند آموزش را با کنترل‌های موجود مدیریت نمایید.

### 2. اجرای تست‌ها
برای اطمینان از صحت عملکرد منطق محیط و کدهای پایه الگوریتم‌ها، تست‌های واحد را اجرا کنید:
```bash
pytest tests/
```

### 3. بازتولید نتایج آزمایش‌ها
جهت اجرای مجدد آزمایش‌ها، ذخیره مدل‌ها و تولید اطلاعات خام، اسکریپت زیر را اجرا کنید:
```bash
python experiments/run_experiments.py
```

### 4. ارزیابی انتقال یادگیری
برای بازتولید آزمایش‌های بخش انتقال یادگیری (Transfer Learning) از دستور زیر استفاده کنید:
```bash
python transfer/transfer_learning.py
```

### 5. تولید نمودارها و گراف‌ها
پس از اجرای آزمایش‌ها، برای تولید تمامی نمودارها، نقشه‌های حرارتی (Heatmaps) و نقشه‌های سیاست (Policies)، دستور زیر را اجرا نمایید:
```bash
python experiments/generate_plots.py
```
پس از اتمام این مرحله، تمام تصاویر در مسیر `results/figures/` در دسترس خواهند بود و فایل گزارش `Final_Report.ipynb` به درستی با این عکس‌ها کار خواهد کرد.

## مستندات کامل
برای مطالعه کامل تحلیل‌ها، تئوری الگوریتم‌ها و نتیجه‌گیری نهایی، به فایل گزارش با نام `Final_Report.ipynb` مراجعه کنید.

## ساختار پوشه‌های پروژه

- agents/: الگوریتم‌های یادگیری تقویتی
- environments/: محیط هزارتو و کدهای ساخت نقشه
- experiments/: آزمایش‌ها، ارزیابی‌ها و کدهای تولید نمودار
- gui/: بخش بصری و رابط کاربری
- results/: محل ذخیره لاگ‌ها، مدل‌های ذخیره‌شده و نمودارها
- transfer/: آزمایش‌های انتقال دانش
- tests/: تست‌های مربوط به ماژول‌های مختلف
